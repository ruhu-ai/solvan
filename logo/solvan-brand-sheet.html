Usage notes

The blue checkpoint is reserved for the mark and for "verified / checkpoint" states in product UI — never as a general decorative accent. The monochrome version uses currentColor, so it inherits any text color. Minimum clear space around the lockup: the height of the wordmark's "O". Icon holds legibility down to 16 px for favicon use.
